# dsh简易绘图能力包（layered-art）

> 用代码作画。五条路线，从「描一张参考图」到「一个部件一块画布地拼出角色」。

作者：**涟崎桦**

---

## 这是什么

一个 DSH 技能包，装好后 DSH 就多了「用代码画画」的能力。五条路线：

| 路线 | 适合 | 产物 |
|---|---|---|
| **A 描图重构** | 已有参考图，要改配色 / 改轮廓 | 一张图 → 多边形骨架 + 内孔 + 调色板 → 换任意配色重画 |
| **B 网格立绘** | 要原创角色、要人体比例正确 | 七头身十块人体 → 生成适配衣服 → Live2D 式层序组合 → 像素细修 |
| **C 方块角色** | 《我的世界》式方块人 | 轴对齐方块 + 侧面竖条梯度，粗细靠像素而不靠几何 |
| **D 像素画** | 任何平涂图 → 像素画 | 分格取众数 + 调色板量化 + 硬边放大 |
| **E 部件装配** | 五官/身体要**分别精修**再合成；要拼豆锯齿风 | 一个部件一块画布 → 按自然尺寸装配 → 高分辨率母版（可选拼豆滤镜） |

## 三条核心命题

1. **结构和配色可以分离。** 图一旦变成「多边形 + 内孔 + 颜色」，
   换配色就是换一张色阶表重跑（0.1 秒），改轮廓就是动几个控制点。
2. **色块和细节要分两个阶段做。** 分区按「面」判定，边界只能沿三角面走 ——
   **一定锯齿**。所有细节（鼻梁、嘴唇、下颌线、腿间缝、上眼睑线）都在像素阶段补。

3. **部件可以有自己的画布。** 眼睛在自己的画布上画够了细节，再按自然尺寸摆进脸 ——
   局部比例不会因为「地方太小」而走形。而**高分辨率母版可以再套一层拼豆滤镜**，
   同一份母版同时出精细版和拼豆版。

## 更新日志

### 1.1.0

新增**路线 E：部件装配**，5 个模块 + 4 个带断言的验证脚本：

- `rig.py` 二维骨架（头高为单位 + 形变 + 姿势 + 分段深度 + 骨相对锚点）
- `bead.py` 拼豆格阵（三条硬约束 + 局部/整体镜像 + 按格取众数）
- `assembly.py` 部件画布 + 装配器（整数格偏移）
- `templates.py` 两套比例（7 头身锥形躯干 / MC 4 头身严格方盒）
- `composite.py` 高分辨率母版合成 + 可选拼豆滤镜
- `skin.py` **MC 皮肤逐面设计**（64×64 标准 UV 布局，已用真实皮肤硬验证）

同时修掉两个会让「可复现」失效的 bug：

- `cv2.kmeans` 没设随机种子 —— 同一张图每次跑出来的块数都不同（实测 475/464/453）
- `cv2.imread` 读不了含中文的路径 —— 解压到中文目录就崩在第一步

**1.0.0** 的源码仍然可用：`git checkout v1.0.0`

## 安装

### 方式一：导入 .dspack

下载 `dsh-simple-drawing-1.1.0.dspack`，在 DSH 里导入即可。技能会落到
`DSH_HOME/skills/layered-art/`。

### 方式二：拷目录

把 `home/skills/layered-art/` 整个拷到你的 `DSH_HOME/skills/` 下。

### 方式三：不用 DSH 也想试

下载 release 里的 `dsh-simple-drawing-1.1.0-skillpack.zip` —— **这就是「赛博拼豆 skill 包」**。
（GitHub 会剥掉资产名里的非 ASCII 字符，所以线上只能叫 ASCII 名。）
解开是一个自带中文上手说明的目录，里面有「30 秒跑出第一张图」的指引，
以及 6 张效果预览图（全部是原创产出，可自由转发）。

### 依赖

```bash
pip install numpy pillow opencv-python-headless
```

路线 B 需要本机 MakeHuman 数据（**只读 npz，不需要运行 MakeHuman**）：

```bash
set MAKEHUMAN_DIR=<你的>/MakeHuman/makehuman       # Windows
export MAKEHUMAN_DIR=<你的>/MakeHuman/makehuman    # macOS / Linux
```

输出目录用 `LAYERED_ART_OUT` 覆盖，默认落在系统临时目录。

## 快速验证

```bash
python <技能目录>/selftest.py        # 期望 39/39
```

自检自己造测试图，不依赖任何外部素材。

## 适合 / 不适合

**适合**：平面着色 / 低多边形 / 像素风 / MC 方块风 / 矢量扁平风。

**不适合**：写实插画（有体积、有布料褶皱、有发丝）超出这套方法的能力。

**不能凭空"想"出角色** —— 路线 B/C 都是在已有几何（MakeHuman 网格 / canon 方块）上做的。
真·文生图需要扩散模型那一层，本技能不提供。

⚠️ 路线 A 是「描」不是「画」：提取出的结构是参考图的衍生品。
当结构素材用没问题（改轮廓 + 换配色 = 新设计），直接当原创作品发布有问题。
